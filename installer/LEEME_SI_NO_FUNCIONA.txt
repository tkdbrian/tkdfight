TKD FIGHT - SOLUCION DE PROBLEMAS
=================================

ERROR: archivos faltantes
-------------------------
El ZIP no se extrajo completo o se eliminaron archivos.
Vuelve a extraer el ZIP completo con la opcion "Extraer todo" y ejecuta
ABRIR_TKD.bat desde la carpeta extraida.

ERROR: no se pudo preparar Microsoft Visual C++ Redistributable x64
-------------------------------------------------------------------
TKD Fight necesita este componente de Microsoft para SQLite. El setup lo
instala antes de TKD Fight; el portable solicita permiso de administrador
si necesita instalarlo o actualizarlo. Acepta el aviso de Windows y espera
a que finalice. Si Windows pide reiniciar, reinicia y vuelve a abrir TKD Fight.

Si el error persiste, no borres la carpeta del torneo. Anota el mensaje
completo y contacta a soporte.

ERROR: el puerto 3001 ya esta ocupado
-------------------------------------
Otra aplicacion o instancia esta usando el puerto. TKD Fight no la cerrara
automaticamente. Cierra la aplicacion identificada o reinicia la PC y vuelve
a intentar.

ERROR: el servidor no respondio en 30 segundos
----------------------------------------------
No cierres el mensaje de error. Revisa el STDERR y STDOUT mostrados y toma
una foto para soporte. Si indica que faltan modulos, vuelve a extraer el ZIP
completo. Si el antivirus bloqueo node.exe, revisa su historial antes de
permitir el archivo.

Windows muestra "Windows protegió tu PC"
----------------------------------------
Windows SmartScreen puede advertir sobre aplicaciones no reconocidas. Solo
continua si recibiste TKD Fight de una fuente de confianza y verificaste el
archivo con quien te lo proporciono.

La ventana se cierra antes de mostrar el error
----------------------------------------------
Abre CMD, cambia a la carpeta de TKD Fight y ejecuta ABRIR_TKD.bat desde
esa ventana para conservar el mensaje. En una instalacion, tambien puedes
iniciarlo desde el acceso directo del menu Inicio.

REQUISITOS
----------
Windows 10/11 de 64 bits y Microsoft Visual C++ Redistributable 2015-2022
x64. Jueces y equipos de torneo deben estar conectados a la misma LAN.
